# 音频录制兼容性优化计划

## 目标

修复音频录制中硬编码 `audio/webm` 格式的问题，通过动态检测浏览器支持的 MIME 类型，确保在不同安卓机型（及 iOS）上的录音功能兼容性。

## 技术方案

1. **新增工具函数** **`getSupportedMimeType`**:

   * 利用 `MediaRecorder.isTypeSupported()` API。

   * 按优先级检测：`audio/webm;codecs=opus` -> `audio/webm` -> `audio/mp4` -> `audio/aac`。
2. **重构** **`LearningInterface.tsx`**:

   * 在 `startRecording` 和 `startPracticeRecording` 中引入动态 MIME 类型检测。

   * 初始化 `MediaRecorder` 时传入检测到的 `mimeType`。

   * 生成 `Blob` 对象时使用实际的 `mimeType`，而非硬编码。

## 预期效果

* **安卓兼容性提升**: 适配那些不支持 WebM 或默认录制为其他格式的安卓设备。

* **iOS 兼容性提升**: 自动适配 Safari 的 `audio/mp4` 录制格式。

* **数据一致性**: 确保上传给 Gemini API 的音频文件头与内容一致。
